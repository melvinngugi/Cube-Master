# Cube Master – Speedcubing Training Platform

Cube Master is a full-stack web application designed to help speedcubers record, analyse, and improve their Rubik’s Cube solving performance. The platform allows users to track solve times, compute official competition averages, review solutions, and visualise cube states generated from scrambles.

The project was developed as part of a software engineering coursework project and demonstrates full-stack application design, API integration, and cloud-hosted database management.

---

## Features

### Solve Tracking
- Record solve times and maintain a complete solve history.
- Toggle +2 penalties and DNF results.
- Delete solves when necessary.
- Automatically compute official WCA-style averages (Ao5, Ao12).

### Scramble Generation
- Generate random scrambles for training.
- Display scramble sequences for each solve.

### Cube Visualisation
- Render cube states directly from scrambles.
- Provide visual previews of the cube state for review.

### Performance Analytics
- Display current and best singles and averages.
- Track progress through solve history and statistics.
- Visualise performance trends with charts.

### Review Dashboard
- Analyse individual solves.
- View solution breakdowns and cube previews.
- Compare solve performance over time.
